# TeleRC v1.1.0rc1 — Android control and balancing

TeleRC Android focuses on manual operation with Wi-Fi, direct LoRa, Test and
Balance. Mission planning/navigation is removed. TeleRC Go remains the minimal
controller; PC TeleRC remains the fleet/mission application.

## Changes

- Full Setup, Controls, Test, Balance and LoRa setup pages.
- Named Balancer Wi-Fi profile and live v0.4 heartbeat, attitude and event diagnostics.
- Legacy v0.3 pre-test retained separately for matching firmware.
- Restored direct LoRa board provisioning with guarded read/save/restart workflow.
- Live sends recheck the captured session and foreground Controls page.
- DISARM remains available when physical permission telemetry expires.
- USB permission denial pauses reconnect until an explicit Connect retry.
- Standalone profiles use the Stop control label.

## Compatibility and installation

Install `TeleRC-v1.1.0rc1.apk`. Its retained signer and higher version code allow
upgrade from v1.0.0. Actual phone installation/settings retention remains to be
checked. The release kit includes the APK, matching source, checksums and notes.

Firmware is unchanged by this app-only update. Android LoRa requires the
matching direct framed USB BASE/ROVER profile. PC fleet/relay LoRa is a separate
protocol; this APK does not add fleet/relay support.

Balancer v0.4.0rc2 supplies standard telemetry, while calibration/direction setup
uses firmware serial diagnostics. The legacy pre-test needs its own versioned
admin replies. Local balancing and paused recovery remain on the robot. PAUSED
can retain ARM and resume output; disarm before handling.

This is a **test candidate**, not stable or field-qualified. Hardware connection,
USB permission behavior on a phone, physical takeover, motor stopping, power,
balancing and RF range remain pending. Legacy Wi-Fi endpoint/CRC validation is
not command authentication. See START_HERE.md and VALIDATION_NOTES.md for the
restrained validation and rollback procedures. Previous releases remain available.
