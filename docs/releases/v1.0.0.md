# TeleRC v1.0.0 — Base prerelease

This is the v1.0.0 ecosystem baseline for restrained testing. It is a prerelease,
not a stable or field-qualified release. Previous releases remain available.

## Included and verified
- Signed Android 1.0.0, version code 1000, original application ID and signing identity.
- 173 JVM tests, debug/release lint, release packaging and signer continuity passed.
- Host regressions and CI ASan/UBSan checks passed.
- Six actual ESP32 firmware profiles compiled with pinned dependencies.
- Complete source, test evidence, compatibility notes, exact provenance and SHA-256 checksums.

The APK and firmware are the unchanged outputs of successful build
39889664702, source c845503175d1d48468ec0201c8992f379c059c52.
Publication verifies the artifact inventory, all checksums, exact signed APK hash,
signer report, firmware image hashes and source pairing before uploading.

## Changes
Manual enable and ARM require fresh physical permission and neutral controls.
Stale takeover data revokes authority. Reconnection never enables control.
The paired bridge validates the exact bounded field command profile and releases
conflicting RC overrides before Guided/HOLD. The current four-input PWM converter
and legacy paired-input converter have separate firmware/wiring profiles.

## Remaining release gates
Legacy Wi-Fi command authentication/replay protection is incomplete. Endpoint
locking and CRC are not authentication. Restrict use to the documented test envelope.
Physical takeover in both directions, stopping time, power/stall behavior, device
installation/upgrade retention, auxiliary OFF behavior and field RF are NOT TESTED.
ArduRover remains responsible for configured vehicle failsafes and mission execution.
A switch/ownership UI indicator does not prove receiver health or manual mode takeover.

Choose the exact board/wiring profile and flash at its documented offsets. Preserve
NVS and back up FC parameters/settings. Do not interchange converters. Pair application
and bridge updates and follow the restrained-wheel procedure before operational use.
See START_HERE.md, REALIGNMENT_V1.md and ecosystem-release.json in the assets.

## Other products
TeleRC Go and PC TeleRC have independent release/build gates in their repositories.
This Base publication does not qualify or publish those applications.
Their v1.0.0 ecosystem baseline retains independently versioned application/firmware
packages; do not treat a matching release tag as wire compatibility.
