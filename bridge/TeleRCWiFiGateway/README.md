# Dedicated Wi-Fi command gateway

Use this sketch on the removable ESP32-S3 command module with `TeleRCMotorController` on the fixed PWM module. It supplies TeleRC-Rover Wi-Fi AP + UDP 14550 and framed UART RX21/TX39 at 115200. No PWM runs on this board. See [common connector, transport selection and provisioning](../SWAPPABLE_GATEWAYS.md).
