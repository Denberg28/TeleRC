# TeleRCLoRaRover

Install RadioLib and the repository's TeleRCLink Arduino library, then configure the actual radio and private pairing key. Unconfigured builds deliberately do not transmit.

Read [the integration, provisioning and wiring guide](../LORA_INTEGRATION.md). Supported initial boards: T3-S3 SX1262 and SX1276; actual RF and motor tests remain required.
